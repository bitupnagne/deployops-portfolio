실행 정책

모든 프로젝트에 함께 적용되는 배포 실행 규칙입니다.

실행 정책 변경은 즉시 적용됩니다. 진행 중인 배포에는 영향을 주지 않습니다.

PROD 배포 제한

PROD 배포 전 TEST 확인 필수

테스트 환경에 먼저 배포해 확인을 마쳐야 운영 배포를 할 수 있습니다.

활성화 시, TEST 배포 완료 + 담당자 테스트 확인 없이는 PROD 배포 요청이 불가합니다.

PROD 배포 승인 필수

운영 배포는 승인권자의 승인을 받아야 실행됩니다.

비활성화해도 선택한 서버 그룹의 추가 승인과 운영 롤백의 필수 승인은 유지됩니다. (권장: 활성)

새 이미지 빌드 전 MR 승인·병합 증거 필수

DeployOps에서 검토·승인·병합한 MR의 확정 commit만 TEST 이미지로 만들 수 있습니다.

비활성화하면 일반 브랜치·태그를 직접 지정하는 기존 빌드 요청도 허용됩니다.

검증된 배포 자동화

자동 승인은 추가 승인 정책이 있는 그룹을 선택하지 않고, TEST 확인 완료 승격의 이미지·digest·commit·브랜치가 모두 일치할 때만 적용됩니다. 수동 배포 전략은 자동 실행하지 않습니다.
검증된 TEST 승격 자동 승인

선택한 그룹에 추가 승인 정책이 없고, 허용 브랜치의 검증된 TEST 산출물을 그대로 PROD로 승격할 때만 승인 단계를 자동 완료합니다.

쉼표 또는 줄바꿈으로 구분합니다. 와일드카드는 지원하지 않으며 정확히 일치하는 브랜치만 허용합니다.

TEST 준비 완료 시 자동 실행
PROD 승인 완료 시 자동 실행

SAFE·WAVE 전략만 자동 실행하며, 시간 제한·Freeze window·동시 실행 제한을 동일하게 적용합니다. TEST도 그룹 추가 승인이 있으면 승인을 모두 마친 준비 상태에서만 자동 실행합니다.
