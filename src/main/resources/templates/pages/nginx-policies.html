Nginx 정책

WEB 서버의 리버스 프록시·정적 사이트·TLS 정책을 승인과 복구 이력으로 관리합니다.

설정과 인증서는 승인 전까지 적용되지 않습니다. 요청자와 승인자는 달라야 하며, 적용 전 현재 설정과 인증서가 자동 백업됩니다.

WAS·TLS·정적 리소스 템플릿 상세 설정

기본 설정 생성에 사용할 WAS, 인증서, 프록시 옵션입니다. 값을 바꾼 뒤 기본 설정 생성 버튼을 누르면 변경안에 반영할 수 있습니다.

STATIC_BUNDLE 컴포넌트의 WebRoot와 같아야 하며 Nginx는 이 경로의 current 릴리스를 제공합니다.
지정한 경로만 API 서버로 전달하며 나머지 경로는 정적 리소스를 제공합니다. API 요청 경로를 그대로 유지합니다.
예: /api/ 또는 /backend/api/ · 경로 끝에 /를 붙이세요.
등록된 WAS와 서비스 포트를 선택하세요. 최대 32개이며 요청 때 주소와 순서를 보관합니다. WEB별로 승인합니다.

VIP는 이 WEB과 같은 환경이며 프로젝트에 연결된 그룹만 선택할 수 있습니다. 프로젝트 VIP 포트 설정 후 표시됩니다. 기본 설정 생성 시 등록된 주소·포트가 원문에 입력됩니다. 기존 원문은 자동 변경하지 않습니다. L4 개별 노드 제어와 무중단은 보장하지 않습니다.
