서버 그룹 개념

그룹은 같이 배포되는 서버 묶음입니다(예: 운영 WAS 2대). 그룹을 펼쳐 그 안에 서버를 넣습니다.

이 화면은 배포가 실제로 나갈 서버를 등록하는 곳입니다.

그룹 없는 서버 그룹 미지정 WEB 서버는 하단에서 Nginx 설정을 확인할 수 있습니다. 그룹이 없으면 어느 프로젝트의 배포 대상도 될 수 없습니다 — 전체 목록에서 확인하고 그룹에 넣어 주세요.

WEB·WAS 각각 유지할 정상 서버 수입니다. 0은 서비스 중단을 허용합니다. 기존 그룹은 0으로 유지되므로 운영 전 확인하세요.

        

        

          
          
          
서버를 한 대씩 교체합니다. 그룹의 공통 정책은 연결된 모든 프로젝트에 적용됩니다.

        

        

          
          
        

        

          
          
          
허용 시간·프로젝트 권한은 기존 공통 정책을 유지합니다. 아래 그룹 승인 정책은 프로젝트 기본 승인에 추가됩니다.

        

        

          
          
          
            
            

          
          
선택한 그룹의 추가 승인을 모두 충족해야 배포할 수 있습니다. 비워도 프로젝트 기본 승인은 유지됩니다. 추가·변경·해제는 최고 관리자만 가능합니다.

        

        

          
          
          
          
서비스 포트는 프로젝트 설정에서 지정합니다. 저장만으로 기존 nginx 설정은 변경되지 않습니다. WEB에서 VIP 템플릿을 생성·승인하고 프로젝트 정책을 연결하세요. L4의 개별 WAS 제외·세션 종료는 제어하지 않으며 순차 교체와 개별 헬스체크만 수행합니다. 무중단은 보장하지 않습니다.
