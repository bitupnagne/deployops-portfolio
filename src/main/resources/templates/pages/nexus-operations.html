저장소와 파일 반입을 관리하고, 백업·복구·이미지 정리를 요청·승인합니다.

현재 TEST·PROD 배포 이미지와 같은 저장소의 최근 복구 이력은 삭제되지 않습니다. 요청자와 승인자는 달라야 합니다.

저장소 조회·생성

프로젝트 등록이나 GitLab 연동 없이 저장된 Nexus 연동 설정으로 저장소를 조회하고 hosted 저장소를 만듭니다.

생성은 확인 후 Nexus에 바로 반영됩니다. Maven 버전 정책은 만들기 화면에서 선택합니다. Docker는 저장된 HTTP 커넥터 포트만 사용할 수 있습니다.

프로젝트 의존성 저장소 · 파일 반입

공용 저장소를 프로젝트별 경로로 나누거나 별도 hosted 저장소를 연결합니다. Docker 이미지는 프로젝트의 이미지 경로와 CI push를 사용합니다.

1. 프로젝트 저장소 연결

반입 저장소는 재배포 금지(Disable redeploy / ALLOW_ONCE)로 설정해야 합니다. Maven RELEASE와 변경하지 않는 RAW 파일을 지원합니다. SNAPSHOT·MIXED 및 기존 메타데이터 갱신은 별도 배포 절차를 사용하세요. Maven은 groupId 경로를 유지하며 지정한 프로젝트 경로 아래 좌표만 반입합니다. RAW는 프로젝트 경로를 파일 앞에 붙입니다. npm은 npm publish를 사용합니다.

반입한 Maven 라이브러리를 프로젝트 CI 빌드에 연결

기존 공용 저장소를 수정하지 않고 프로젝트 전용 group에 반입 저장소와 기존 저장소를 묶습니다. 승인된 Maven CI 템플릿의 --settings "$MAVEN_SETTINGS_FILE" 경로로 사용됩니다. RAW·npm은 이 연결을 지원하지 않습니다.

NEXUS_MAVEN_USER·NEXUS_MAVEN_PASSWORD는 프로젝트 CI 변수 화면에서 읽기 권한 계정으로 등록하세요. 암호는 아래 XML에 포함하지 않습니다. 기존 MAVEN_SETTINGS_FILE은 적용 확인 후 전체 교체됩니다. 외부 proxy를 포함한 기존 group은 폐쇄망에서 모든 의존성을 제공하지 못할 수 있습니다.


      
연결 준비와 파이프라인 실제 빌드 성공은 별도로 확인합니다.

    

    
2. 반입할 파일 선택

    

      

      

      

    

    
폴더 선택 시 최상위 폴더 이름을 제외한 상대 경로를 유지합니다. Maven은 JAR만이 아니라 해당 POM·메타데이터도 함께 반입하세요. ZIP을 자동 해제하거나 누락 의존성을 생성하지 않습니다. 전체 파일 크기 제한은 없으며 전송은 작은 청크로 나눕니다. 서버 임시 디스크와 Nexus에 실제 파일을 저장할 공간은 필요합니다.

    
3. 전송 및 등록 결과 확인

    

    
새로고침 후 같은 파일을 다시 선택하면 미완료 파일의 기존 내용을 확인하고 이어서 전송합니다. 파일 전송 100%와 Nexus 등록 완료는 별도입니다. 등록 중 취소하면 결과 확인이 필요할 수 있으며 원격 파일을 자동 삭제하지 않습니다.

Nexus 백업

      
백업 중 Nexus가 잠시 중지됩니다. DB·파일 blob·암호화 키를 함께 보관한 뒤 원래 실행 상태를 복구합니다.

      

    
요청자와 승인자는 달라야 합니다. 외부 GitLab·CLI 게시 작업을 중지한 유지보수 창에서 승인하세요. 완료는 백업과 원본 상태 복구를 뜻하며, 격리 복원 검증 완료를 뜻하지 않습니다. 실행 중 취소·자동 재실행은 제공하지 않습니다.

    
처음 설치한 서버에서 실행기가 미준비이면 demo-deploy의 대화형 설치기에서 11. 백업·복구 준비 → 1. Nexus 준비를 진행한 뒤 새로고침하세요.

Nexus 격리복원

      
완료 백업 행에서 격리복원을 신청합니다. 요청자와 다른 승인자가 승인하면 root 실행기가 새 clone을 만듭니다. 미확정 요청은 실행 전 실패 상태 또는 이미 생성된 clone의 준비 상태를 별도로 확인할 수 있습니다. 재확인은 복원을 재실행하지 않으며 정상 GUI의 여섯 항목 확인을 대신하지 않습니다.

    
원본과 기존 clone을 덮어쓰지 않습니다. 건강 준비는 기능검증 완료가 아닙니다. 미확정 실행은 재실행·자동 정리하지 않으며 차단을 유지합니다. 운영자 확인은 정상 Nexus GUI의 수동 확인 기록입니다.

복원본 운영 전환

      
정상 Nexus 화면에서 기능·자료를 확인한 복원본을 기존 운영 접속점으로 전환합니다. 전환 전 컨테이너·볼륨·키는 복구용으로 보존합니다.

      

    
요청자와 승인자는 달라야 합니다. 외부 GitLab Runner·CLI 게시 작업을 중지한 유지보수 창에서 승인하세요. 백업 이후 저장한 자료·설정은 복원본에 포함되지 않습니다. 결과가 미확정이면 실행을 반복하지 말고 표시된 컨테이너와 실행기 결과를 확인하세요.

    
운영 전환이 완료되면 기존 격리 복원본 컨테이너는 중지됩니다. 위 복원 이력의 내부 bridge 주소 대신, 설정된 일반 Nexus 접속 주소와 아래 운영 컨테이너 식별 정보를 사용하세요.
