배포 대상 서버 그룹

이 프로젝트와 환경에 연결된 그룹 중 이번 요청에 반영할 그룹을 선택하세요. 승인 후 대상은 고정됩니다.

프로젝트와 환경을 먼저 선택해 주세요.

선택한 그룹에 추가 승인 정책이 있습니다. TEST 배포도 수동 승인이 필요하며, 프로젝트 승인 정책을 먼저 거친 뒤 그룹 ID 순서대로 추가 승인합니다. 정책 상세는 서버 그룹 화면에서 확인하세요.

이 화면에서는 기존 이미지를 배포합니다. 새 빌드는 MR 승인·병합 화면에서 진행합니다.

새로 빌드 후 배포

프로젝트를 선택하면 GitLab 브랜치 목록을 조회합니다.

기존 이미지로 배포

프로젝트를 고르면 올라와 있는 이미지를 불러옵니다.

선택한 프로젝트와 배포 환경에 등록된 WAS·WEB 서버 대상을 모두 포함합니다.

교체 순서와 그룹의 가용성 정책을 함께 적용합니다. 순서 선택만으로 무중단이 보장되지는 않습니다. 수동 전략은 실패 시 중단(STOP) 그룹에서만 사용할 수 있습니다. 그룹 자동 복구(ROLLBACK)는 순차·호기별 전략을 사용하세요.

선택한 그룹에 자동 복구(ROLLBACK) 정책이 있어 수동 전략으로 요청할 수 없습니다.
