Ollama 예: http://HOST:11434 · vLLM 예: http://HOST:8000

등록 여부 확인 중

낮을수록 일관된 응답, 높을수록 창의적인 응답이 나옵니다.
Anthropic Opus 4.7 이상(Claude 5 계열 포함)은 이 값을 받지 않아 자동으로 제외됩니다 — 응답 성향은 시스템 프롬프트로 조정하세요.

기능 설정

배포 위험도 자동 분석
배포 요청 생성 시 변경 내용을 분석해 위험도를 낮음, 보통, 높음으로 자동 평가합니다.
승인자 자동 추천
배포 내용과 변경 이력을 기반으로 적합한 승인자를 추천합니다.
커밋 변경 요약
GitLab 커밋 로그를 요약해 승인자가 변경 내용을 빠르게 파악할 수 있게 합니다.
배포 실패 원인 진단
배포 실패 시 로그를 분석해 원인과 조치 방향을 제안합니다.
프로젝트 로그 읽기 (챗봇)
챗봇이 "○○ 로그 분석해줘" 요청 시 프로젝트에 설정된 로그를 읽어 분석합니다. 끄면 로그를 전혀 읽지 않습니다.

시스템 프롬프트

AI 응답의 기본 지침을 설정합니다. 비워 두면 기본값이 사용됩니다.
