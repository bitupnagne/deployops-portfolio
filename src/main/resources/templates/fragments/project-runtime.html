런타임 설정

저장한 설정은 즉시 서버에 적용되지 않습니다. 새로운 배포 요청에서 환경변수 리비전과 로그 저장 설정을 확인하고 승인한 뒤 적용합니다. 비밀 값은 다시 조회하거나 다운로드할 수 없습니다.

컴포넌트는 프로젝트 기본 설정을 상속하거나 별도 리비전을 선택할 수 있습니다. 적용하지 않음을 선택하면 상속도 해제합니다. 정적 파일·프록시는 컨테이너 런타임 설정 대상이 아닙니다.

로그 저장·임시 공간을 사용하려면 배포 단위에 숫자 형식의 비루트 UID:GID를 설정해 주세요. 환경변수는 Docker 관리자에게 조회될 수 있습니다. 상속을 선택하면 이 배포 단위의 로그·임시 공간 설정도 기본 설정을 따릅니다.

탭을 열면 설정을 불러옵니다.

새 환경변수 리비전

KEY=VALUE 형식으로 한 줄씩 입력해 주세요. 주석·export·중복 키는 사용할 수 없습니다. UTF-8 파일의 줄바꿈은 LF를 사용하세요. 서버에는 암호화해서 보관하며, 아래 저장은 기존 리비전을 변경하지 않습니다.

배포에 사용할 설정

기본 30초, 1~300초입니다. 해당 환경·배포 단위의 새 배포 요청과 서비스 정지·재기동에 사용합니다. 유예 시간이 지나면 강제 종료될 수 있습니다.

0은 사용하지 않음, 사용 시 16~512MiB를 입력합니다.

관리형 파일 로그

선택한 서버의 demo-app.log를 읽습니다. 로그 유지 설정으로 배포된 컨테이너만 조회할 수 있으며, 로그에는 애플리케이션 데이터가 포함될 수 있습니다.

파일 로그 조회 권한을 확인한 뒤 사용할 수 있습니다.
