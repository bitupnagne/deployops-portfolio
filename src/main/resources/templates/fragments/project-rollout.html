롤링 배포 nginx 연결

이 프로젝트의 WAS로 요청을 전달하는 WEB 정책을 연결합니다. nginx가 개별 WAS에 직접 연결된 경우 교체 대상을 제외하고 정상 확인 후 복귀합니다. 외부 VIP를 사용하면 L4 멤버를 제어하지 않고 개별 WAS를 순차 교체·헬스체크하므로 무중단은 보장하지 않습니다. 연결 저장만으로 nginx 설정이 변경되지는 않습니다.

서버 매핑에 등록된 같은 환경의 WEB에서 적용 완료된 프록시 정책만 표시합니다. 다른 프로젝트가 연결한 정책은 선택할 수 없습니다. 먼저 서버 그룹의 WEB nginx 화면에서 정책을 적용하세요.
