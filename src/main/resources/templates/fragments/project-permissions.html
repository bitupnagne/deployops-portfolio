직접 부여 권한

체크를 해제하면 해당 직접 권한을 회수합니다. 기존 ALL 항목은 자동 변환하지 않습니다. 조회·요청·승인·실행은 서로 다른 권한입니다.

MR 변경내용과 diff를 검토하려면 프로젝트 조회와 MR 검토 권한이 모두 필요합니다. MR 승인과 병합은 각각 별도 권한입니다.

런타임 설정 관리와 런타임 파일 로그 조회는 TEST·PROD별 별도 권한입니다. 설정 관리 권한만으로 승인하거나 배포를 실행할 수 없습니다.
